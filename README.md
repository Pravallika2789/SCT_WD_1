# 🌐  Responsive Landing Page

## 📌 Overview

This project is a Responsive Landing Page developed as part of the SkillCraft Technology Web Development Internship.

The application features a modern and interactive navigation menu that changes appearance while scrolling and responds to user interactions. The website is fully responsive and provides a seamless experience across desktop, tablet, and mobile devices.

---

## 🚀 Features

* Responsive Design
* Interactive Navigation Menu
* Scroll-Based Navigation Effects
* Hover Animations
* Mobile-Friendly Layout
* Modern User Interface
* Smooth User Experience
* Cross-Browser Compatibility

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📷 Project Preview

The Responsive Landing Page allows users to:
